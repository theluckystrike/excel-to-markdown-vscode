# Try Excel to Markdown here

This is a new, unsaved file. Nothing you do here changes a file on disk.

Select the five lines below, then run Excel to Markdown: Convert CSV/TSV to Markdown Table from the Command Palette.

id,product,price,note

## 2. Format a table

Put the cursor anywhere in this table and run Excel to Markdown: Format Markdown Table.

## 3. Back to CSV

With the cursor in a table, run Excel to Markdown: Convert Markdown Table to CSV (or to TSV).
