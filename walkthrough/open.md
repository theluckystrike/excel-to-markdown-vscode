# Copy a sheet or range from a workbook

Right-click an `.xlsx`, `.xlsm`, `.xls`, `.ods`, `.csv` or `.tsv` file in the Explorer and pick Open Spreadsheet as Markdown Table.

- Sheet picks the sheet.
- Range takes A1 notation: `A1:D20`, `B:D` or `2:10`. Leave it empty for the whole sheet.
- Format writes Markdown, HTML, AsciiDoc, Jira, CSV or TSV.
- Copy puts the table on the clipboard. Insert at cursor adds it to the last file you edited.

Cells come as they are stored: plain numbers and ISO dates (2026-01-05). The sample workbook has three sheets: prices with links, a quarterly report with merged cells, and a team list with Japanese and Korean names.
