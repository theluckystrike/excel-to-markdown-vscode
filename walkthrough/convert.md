# Format tables, and go back to CSV

- Convert CSV/TSV to Markdown Table: select CSV or TSV text and run it. In a `.csv` or `.tsv` file with nothing selected, the whole file opens as a Markdown table in a new tab, and the CSV file is not changed.
- Format Markdown Table: put the cursor anywhere in a table. Columns are padded so the pipes line up, also with Chinese, Japanese, Korean and emoji text, and the alignment row is kept.
- Convert Markdown Table to CSV and to TSV: the table under the cursor is replaced with CSV or TSV text, and `<br>` becomes a line break again.

The sample opens in a new unsaved tab, so you can try each command there.
